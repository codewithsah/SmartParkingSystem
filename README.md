Smart Parking Management System ek high-performance desktop application hai jo modern parking logistics ko handle karne ke liye banayi gayi hai. Ye manual record-keeping ko ek automated, real-time database-driven solution se replace karta hai.🎯 Project ObjectivesReal-time Monitoring: Dashboard par live occupancy tracking (500 slots capacity).Automated Billing: Entry aur exit timestamps ke basis par exact fee calculate karna.Data Validation: Indian number plates aur mobile numbers ke liye strict Regex verification.Revenue Auditing: Daily earnings ko monitor karne ke liye historical data logging.✨ Key FeaturesDynamic Pricing Engine: Vehicle type ke basis par alag rates (SUV, EV, Car, Bike).Grace Period Logic: 2 minute ke andar exit karne par ₹0 charge (User-friendly feature).Interactive Dashboard: Progress bars aur color-coded status indicators ka use.Local Persistence: Software band hone par bhi data SQLite mein secure rehta hai.🛠️ Tech Stack & ToolsLanguage: C++17 (for core logic and performance).Framework: Qt 6.x Widgets (for GUI design).Database: SQLite (for RDBMS operations).Build System: CMake / QMake.📂 Project StructurePlaintext├── main.cpp            # Application entry point
├── mainwindow.cpp      # Backend logic & Database operations
├── mainwindow.h        # Class & UI declarations
├── mainwindow.ui       # Visual layout design (XML)
├── SmartParking.pro    # Qt Project configuration
└── parking_system.db   # SQLite Database file
